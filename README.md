# Scale of the Universe

A journey through the powers of ten — and the increasingly outrageous architecture of reality.

**Live:** https://amyleesterling.github.io/explore-the-verse-2-/

One continuous, spring-smoothed logarithmic zoom across 42 orders of magnitude — proton to observable universe — with a focal object always smoothly centered and the powers-of-ten readout updating in real time. Scroll, drag, click, autoplay, or use the keyboard.

## Local development

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # static export → out/
npm run typecheck
```

Built with Next.js 14, TypeScript, Tailwind, and Framer Motion. Statically exported and deployed to GitHub Pages from `main` via `.github/workflows/deploy.yml`.
